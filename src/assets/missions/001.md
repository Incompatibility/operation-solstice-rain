# Operation // Solstice Rain

## Mission 01: The Drop
*UNION NAVAL COMMAND // PRIORITY TRANSMISSION*

**VESSEL:** UNS-CV Rio Grande

**AO:** Cressidium // Nov Elysia

**DEPLOYMENT:** First Wave

**THREAT STATUS:** ACTIVE HOSTILITIES

# Situation

Diplomatic negotiations between Union and the
governments of Cressidium have been interrupted
by a sudden military offensive.

Vestan Sovereignty mechanized forces have
entered Nov Elysia. Communications with the
planetary surface have been lost.

Captain Farris and Ambassador Nilan Bannerjee
remain unaccounted for within the city.

Union Command has authorized a limited
rescue operation.

# Goals

- Deploy to Nov Elysia with the first landing wave.
- Rendezvous at Forward Operating Base Saber.
- Establish contact with Union ground personnel.
- Await updated operational orders.

# Stakes

- Delays will narrow the opportunity to locate
  and recover missing Union personnel.
- Hostile resistance may compromise the
  landing operation and subsequent extraction.

# Mission Parameters

**RULES OF ENGAGEMENT:**
Engage hostile forces only if fired upon.

**ENEMY PRESENCE:**
Vestan mechanized units confirmed in the AO.

**COMMUNICATIONS:**
One squad member must carry an Omnihook
for contact with the Rio Grande.

**RESERVES:**
None assigned.
